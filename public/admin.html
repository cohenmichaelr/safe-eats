What a county selection does

    

      DBPR publishes district files, not county ones, so picking a
      single county still downloads that district's whole extract — the selection
      narrows what is written, not what is fetched. Loading never deletes, so
      refreshing one county leaves the others exactly as they were. Geocoding is
      not county-scoped: it resolves every address still missing coordinates.
